# UIkit Dashboard Admin Links

A tiny companion plugin for [YOURLS](https://yourls.org/) and the [UIkit Skin](https://github.com/uglyeoin/yourls-ui-kit).

The skin's Dashboard lists "Top performers" and "Recently created" short URLs as links to the redirect itself. This plugin rewrites those links so they open the admin **Links** list filtered to that keyword instead, where the row actions (stats, edit, delete, ...) are available.

## Installation

1. Clone or copy this folder into `user/plugins/` of your YOURLS install.
2. Activate **UIkit Dashboard Admin Links** under Manage Plugins.

Requires the UIkit Skin to be active; it does nothing (harmlessly) without it.
